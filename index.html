기기별 알림 등록

휴가 전날 오후 7시 · 휴가 당일 오전 7시 알림을 받을 기기를 등록합니다. 기기마다 알림을 등록하고 원격 수신 테스트로 확인할 수 있습니다.

아이폰은 Safari에서 홈 화면에 추가한 앱으로 열어야 푸시 알림을 허용할 수 있습니다. 알림 권한은 버튼을 직접 눌렀을 때 요청합니다.
알림 시점 설정
화면 알림 표시 시점
현재는 미리보기 버전마감 알림은 홈 화면의 상태 표시로만 작동합니다. 원격 푸시 테스트는 별도 서버 함수 배포 후 작동합니다. 이 화면은 앱 내부 일정 표시를 테스트하기 위한 것입니다.
데이터 관리
회원가입과 로그인은 Supabase Auth에 연결됩니다. 가족정보·입사일·본인 생년월일은 Supabase에 저장되고 로그인 시 불러옵니다. 신청 상태와 알림 설정은 현재 브라우저에만 저장되므로 기기 간 동기화되지 않습니다.
