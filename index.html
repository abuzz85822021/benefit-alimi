🔋 갤럭시 알림이 오지 않을 때

① 휴대폰 설정 → 배터리 → 백그라운드 사용 제한
② 절전 상태 앱 / 초절전 상태 앱에서 Chrome 또는 혜택알리미가 있는지 확인
③ 있다면 목록에서 제거한 뒤 원격 테스트를 다시 실행해 주세요.

기종과 One UI 버전에 따라 메뉴 이름이 다를 수 있습니다. 이 설정은 보안상 앱이 자동으로 변경할 수 없습니다. 알림 권한 및 방해 금지 설정도 확인해 주세요.

일반 사용자에게는 표시되지 않는 관리자용 공개 키입니다.

휴가 알림을 켜볼까요?
휴가 전날 오후 7시, 당일 오전 7시 알림을 받을 수 있어요. 먼저 기기를 등록하고 실제 수신을 확인해 보세요.
① 이 기기 알림 등록
② 서버에서 원격 테스트 발송
③ 실제 알림 도착 확인
갤럭시에서는 Chrome 또는 혜택알리미가 절전·초절전 앱에 포함되면 알림이 늦거나 도착하지 않을 수 있습니다. 웹앱이 이 설정을 자동 변경할 수는 없어요.
